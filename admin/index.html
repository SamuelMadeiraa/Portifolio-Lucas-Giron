Conectar ao GitHub

O painel salva as alterações e os arquivos direto no repositório do site. Isso só precisa ser feito uma vez por navegador.

Como criar o token (2 minutos)
  1. Abra github.com/settings/personal-access-tokens/new.
  2. Dê um nome (ex.: admin do portfólio) e escolha uma validade.
  3. Em Repository access, marque Only select repositories e escolha o repositório do site.
  4. Em Permissions → Repository permissions → Contents, escolha Read and write.
  5. Clique em Generate token, copie e cole aqui.

O token só dá acesso a esse repositório e fica guardado criptografado com a sua senha, só neste navegador.

Este navegador não permite guardar o token com segurança (abra o painel por https). Você vai precisar colar o token a cada acesso.

Modo local: nada é publicado. “Baixar arquivos” gera o content.json e os arquivos enviados para você subir manualmente.
